# Changelog

From 0.1.1 on, release notes are generated by git-cliff from Conventional Commits and
published on [GitHub Releases](https://github.com/bcmyguest/opencode-clm/releases).

## 0.1.0

First release: Context Language Model mode for OpenCode 1.18, ported from pi-clm 1.0.0.

- Context mirror `LIVE_CONTEXT.md` per session, rewritten before each request; the model
  edits it with bash, and the plugin applies the edit on the next request.
- Edit gate (`fit`, `shrink`, `none`; default `fit`), with a verdict appended to each tool
  call that writes the mirror and a `[CLM]` note on the next request.
- Projection checkpoints in `state.json` that survive OpenCode's prune; the plugin drops
  the revision when the stored history no longer matches, except after a compaction,
  where it rebases onto the summary and keeps pins and continuity annotations.
- Budget tiers (default 32,000 tokens, reserve 2,048, reminders at 25/50/75% and at
  budget − reserve) with a calibrated chars/4 estimate that counts the system prompt and
  tool schemas; with `guard: "off"` budget notices omit the guard sentence.
- Optional per-result observation cap; overflow guard that withholds the oldest new tool
  results to files above budget − reserve.
- Continuity tools `clm_annotate` (pin, continuity, archive) and `clm_recall`.
- Commands `/clm [status | path | on | off | reset]` and `/clm-compact [instructions]`.
- Skill `clm-context`; optional steering document, with pi-clm's house brief bundled.
- Settings through plugin options or `CLM_*` environment variables.
- Hooks fail open; user-defined `clm` and `clm-compact` commands are kept and left alone.
